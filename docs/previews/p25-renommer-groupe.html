Deux choix indépendants : une variante pour Renommer, une pour l'envoi au groupe (elles se combinent toutes). 1 · Renommer un favori (P25.5)

Actuel (0.4.192)

Un appui long sur une puce ne propose que Appliquer et Supprimer (et « Rétablir l'original » pour un favori fourni mis à jour). Pour changer un nom, il faut aujourd'hui recréer le favori sous un autre nom puis supprimer l'ancien.

Commun à toutes les variantes

  • Le champ s'ouvre avec le nom actuel, tout sélectionné : on tape directement le nouveau nom.
  • Renommer reste grisé tant que le nom est vide ou inchangé. Un nom déjà porté par un autre favori : « Un autre favori porte déjà ce nom. » sous le champ, bouton grisé (deux puces au même nom ne se distinguent pas).
  • Message en bas : « Favori renommé : nouveau nom » avec Annuler, qui remet l'ancien nom.
  • Le favori appliqué change de nom tout de suite dans le bandeau (« Rando été 2026 (modifié) · 6 cartes »). Ses cartes ne changent pas.
  • Favori fourni (Rando été, Rando Hiver) : le nouveau nom devient votre version du favori, comme « Mettre à jour » (ADR-108) ; « Rétablir l'original » ramène le nom et les réglages livrés.

2 · Envoyer des favoris au groupe (P25.4)

Actuel (0.4.192)

Les favoris ne partent que par un fichier .toolmap et le partage d'Android. Le groupe partage déjà des waypoints, tracés et croquis (P27) : bloc « Dans le groupe », feuille « Partager dans le groupe », fiche d'un partage. L'aperçu validé de P25.0 (« C · Poids ») ne montre ni l'envoi au groupe ni sa réception : d'où cet aperçu.

Commun à toutes les variantes

  • Ce qui part : exactement le contenu du fichier .toolmap (les favoris cochés, la définition des cartes ajoutées, jamais les tuiles), compressé et chiffré avec la clé du groupe. Même choix de la clé qu'avec le fichier (« Retirer la clé » par défaut).
  • Taille : compressé, un favori de cartes fournies pèse quelques centaines d'octets ; la limite est d'environ 12 Ko compressés (des dizaines de favoris, ou plusieurs cartes ajoutées). Au-delà : « Trop gros pour le groupe : envoyez le fichier avec Partager… ». Rien n'est découpé.
  • Réception : rien n'est ajouté ni appliqué sans le destinataire. « Ajouter » ouvre la feuille déjà connue « Ajouter N favoris ? » (P25.3) : nom déjà pris → « (2) », carte ajoutée, clé à saisir.
  • Le bouton du groupe n'apparaît que si vous êtes dans un groupe.
  • Variantes A, C, D : le favori reste dans le groupe (comme un tracé de P27) et arrive aussi chez ceux qui rejoignent plus tard ; par le serveur, il demande les règles Firebase de P27.1 (à republier dans la console).

Votre choix
