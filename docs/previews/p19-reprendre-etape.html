Reprendre une étape au réticule : 3 variantes

Demande de l'utilisateur (2026-10-28) : dans « Itinéraire », pouvoir reprendre la main sur une étape en la survolant avec le réticule, avec la même mécanique que « Ajouter ici » qui devient « Insérer ici » quand le réticule survole le tracé.

Aujourd'hui, le réticule posé sur une étape laisse le bouton sur « Ajouter ici » (une nouvelle étape en fin d'itinéraire, posée sur l'ancienne). Pour déplacer l'étape, il faut la toucher du doigt pour la sélectionner, déplacer la carte, puis toucher « Déplacer ici ».

Commun à toutes les variantes : le survol est repéré comme pour « Insérer ici », à la même distance (24 dp autour du réticule). Une étape passe avant le tracé : sur une étape, jamais « Insérer ici ». Le déplacement compte pour un seul « Annuler ». Les maquettes sont au thème sombre, avec l'itinéraire A → 1 → B ; le réticule est sur l'étape 1.
