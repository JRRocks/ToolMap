Partages du groupe

Créer ou partager un waypoint, un tracé ou un croquis dans le groupe de partage de position. Ce qui est partagé ne vit que dans le groupe. On le crée depuis l'écran du groupe, sous « Messages », pour le distinguer de ce qui est à soi. Chaque partage envoie un message automatique, par exemple « Marie a partagé un croquis ». Le cadre pointillé turquoise marque ce qui est nouveau.
