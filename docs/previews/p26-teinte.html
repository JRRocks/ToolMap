P26 · Couleurs d'un calque : curseur « Teinte » et panneau transparent pendant le réglage

Validé le 2026-10-29 : « T2 - A » : piste arc-en-ciel pour « Teinte », et A, le curseur tenu reste seul sur une pastille pendant que le panneau s'efface. ADR-095, P26.6.

Demande (2026-10-29) : « Rajoute le slide pour Hue, dans la correction de couleur d'un calque / carte. Rends le menu transparent pendant l'utilisation du slider afin de voir les effets rendus sur la carte. »
Aucun code avant votre choix. Les téléphones marqués « Essayez » fonctionnent : faites glisser un curseur, la carte change vraiment (même calcul que MapLibre).
